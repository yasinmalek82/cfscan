# CF Scanner برای آیفون (Pythonista)

**ایده در یک خط:** IP تمیز کلادفلر فقط به اینترنت مشتری بستگی دارد، نه به سرور، چون سرور را
SNI انتخاب می‌کند. پس **یک رکورد، `ip1`، برای همهٔ کانفیگ‌های CDN همهٔ سرورها کافی است.**

برنامه روی هر اینترنتی که گوشی شما به آن وصل است IPها را تست می‌کند و نتیجه را در یک **جدول
پوشش** نگه می‌دارد (هر IP روی هر اینترنت). بعد `ip1` را به IPهایی می‌دهد که روی بیشترین
اینترنت‌ها کار می‌کنند.

| فایل | کاربرد |
|---|---|
| `cfscan_ios.py` | برنامه |
| `pythonista_smoke_test.py` | تست اولیهٔ یک‌صفحه‌ای (اختیاری) |

---

## ۱. کلادفلر (یک بار)

1. **دامنهٔ CDN هر سرور** با **ابر نارنجی**، یک سطح زیر دامنهٔ اصلی. مثلاً `de.example.com`
   و `tr.example.com`. دامنهٔ دوسطحی مثل `de.cdn.example.com` با گواهی رایگان کلادفلر کار نمی‌کند.
2. **رکورد `ip1.example.com`** با **ابر خاکستری (DNS only)**. اولین اسکن خودش پرش می‌کند.
3. **توکن API:** `My Profile → API Tokens → Create Token → Edit zone DNS`
   - فقط دامنهٔ خودتان را انتخاب کنید.
   - دسترسی `Zone → Zone → Read` را هم اضافه کنید، یا Zone ID را در برنامه وارد کنید.
4. **پیشنهاد:** یک دامنهٔ ارزان دوم هم در کلادفلر داشته باشید. اگر SNI دامنهٔ اصلی روی یک
   اپراتور فیلتر شد، فقط SNI هاست‌ها را در پنل عوض می‌کنید.

## ۲. پنل PasarGuard

هاست CDN فقط برای **۱ یا ۲ سرور اصلی** لازم است:

| فیلد | مقدار |
|---|---|
| address | `ip1.example.com` (برای همه یکی) |
| sni و host | دامنهٔ CDN همان سرور، مثلاً `de.example.com` |
| ALPN | `http/1.1` |
| fingerprint | `chrome` |

لیست پیشنهادی برای مشتری، به ترتیب (فیلد priority):

```
📊 {DATA_LEFT} مانده · ⏳ {DAYS_LEFT} روز
DE ⚡              Reality
DE 🛡              CDN (address: ip1)
SWE ⚡
TR ⚡ 🎮 گیم
TR 🛡              CDN (address: ip1)
UK ⚡ 📈 ترید
⛔ اشتراک تمام شده — تمدید: @…     (status: expired, limited)
```

متن راهنما (announce): «اول ⚡، اگر وصل نشد 🛡 · برای انتخاب، پینگ همه را بگیرید.»

## ۳. نصب روی آیفون

1. فایل `cfscan_ios.py` را در Files ذخیره کنید.
2. در Pythonista، در فهرست فایل‌ها دکمهٔ `+` را بزنید، `Import…` را انتخاب کنید و فایل را وارد کنید.
3. اجرا کنید (▶). بار اول دو سؤال می‌پرسد:
   - **سرور CDN:** دامنه و path
   - **توکن و نام `ip1`:** نام `ip1` خودکار پیشنهاد می‌شود.
4. **آیکون روی صفحهٔ اصلی:** در تنظیمات Pythonista، بخش Shortcuts / Home Screen.

## ۴. استفاده: فقط یک دکمه

1. **VPN را خاموش کنید.** نوار وضعیت باید سبز باشد: «اینترنت ایران».
2. **بالای صفحه انتخاب کنید الان روی کدام اینترنت هستید:** همراه اول، ایرانسل، خانگی یا …
3. **«اسکن این اینترنت»** را بزنید. برنامه:
   1. IPهای فعلی `ip1` را روی همین اینترنت تست می‌کند. اگر سالم باشند، کار تمام است.
   2. اگر نه، اسکن می‌کند. اول IPهایی که روی اینترنت‌های دیگر کار کرده‌اند تست می‌شوند.
   3. IPهایی را انتخاب می‌کند که روی **بیشترین اینترنت‌ها** کار می‌کنند، با کمترین «بدترین پینگ»،
      و روی **همهٔ سرورهای CDN** با درخواست WebSocket تأییدشان می‌کند.
   4. `ip1` را در کلادفلر به‌روز می‌کند.
4. **سیم را عوض کنید و دوباره بزنید.** بعد از اسکن روی هر سه اینترنت، کارت `ip1` در صفحهٔ اصلی
   نشان می‌دهد هر IP روی کدام اینترنت کار می‌کند:

```
ip1 · ip1.example.com
104.19.201.44
[همراه اول 52] [ایرانسل 80] [خانگی ✕]
پوشش: همراه اول ✓ · ایرانسل ✓ · خانگی ✓
```

**اگر هیچ IP مشترکی با یک اینترنت (مثلاً خانگی) نباشد:**
- **بدون `ip2`:** `ip1` برای آن اینترنت یک IP جدا هم می‌گیرد، تا هیچ اینترنتی بی‌IP نماند.
- **با `ip2`:** اگر این وضعیت ادامه داشت، رکورد `ip2` را در تنظیمات فعال کنید و در پنل برای
  همان سرور یک هاست CDN دوم با `address: ip2` بسازید. از آن به بعد IP جدای آن اینترنت روی
  `ip2` می‌رود.

نتیجهٔ هر اینترنت ۴۸ ساعت معتبر است. قابل تغییر در «تنظیمات ← پیشرفته».

## ۵. منوها

**تنظیمات:**
- توکن و رکوردها
- سرورهای CDN (فقط برای تأیید)
- اینترنت‌ها: مثلاً رایتل یا شاتل اضافه کنید
- پیشرفته

**ابزارها:**
- جدول همهٔ IPها (★ = در رکورد)
- تاریخچه
- تست یک IP روی این اینترنت
- تنظیم دستی و برگرداندن `ip1`
- تست کلادفلر
- بررسی اتصال
- رنج‌های کلادفلر
- پاک کردن حافظه
- کپی و وارد کردن تنظیمات
- کپی لاگ

**روی ردیف‌های صفحهٔ اسکن** بزنید: کپی، گذاشتن روی `ip1` یا `ip2`، یا تست دوباره.

**به‌روزرسانی از نسخه‌های قبلی:**
- سرورها و اپراتورها منتقل می‌شوند و اپراتورها «اینترنت» می‌شوند.
- IPهای خوب قبلی وارد جدول پوشش می‌شوند.
- زیردامنه‌های قدیمی (`mci.cdn…` و غیره) در کلادفلر دست نمی‌خورند. بعد از اینکه هاست‌های پنل
  را روی `ip1` بردید، یکی دو هفته صبر کنید و بعد پاکشان کنید.

## رفع اشکال

| پیام | معنی |
|---|---|
| «VPN روشن است» | کلادفلر شما را خارج از ایران دیده است. |
| «همه timeout شدند» | اینترنت قطع است یا همهٔ کاندیدها بسته‌اند؛ دوباره اسکن کنید. |
| «اتصال TLS قطع می‌شود» | احتمالاً SNI دامنهٔ CDN روی این اینترنت فیلتر است؛ دامنهٔ ذخیره را جایگزین کنید. |
| «پاسخ 404» | path سرور با inbound یکی نیست. |
| «خطای 5xx» | کلادفلر به سرور وصل نشد؛ سرور، پورت یا حالت SSL را بررسی کنید. |
| «zone not found» / «اجازهٔ دیدن دامنه‌ها» | دسترسی `Zone:Read` را به توکن بدهید یا Zone ID را وارد کنید. |
| «رد شد روی سرور دیگر» | آن IP روی یکی از سرورها با WebSocket جواب نداد و کنار گذاشته شد. |

اگر برنامه بسته شد: «ابزارها ← کپی لاگ برای گزارش خطا» را بزنید و متن را بفرستید.
