# CF Scanner برای آیفون (Pythonista)

برنامه برای هر سرور CDN (آلمان، ترکیه، …) رکوردهای آدرس کلادفلر را تمیز نگه می‌دارد:

| رکورد | مثال | برای | کی عوض می‌شود |
|---|---|---|---|
| **موبایل** | `cdn1.germany.example.com` | همراه اول و ایرانسل | با اسکن روی همراه اول یا ایرانسل |
| **خانگی** (اختیاری) | `cdn2.germany.example.com` | اینترنت خانگی | فقط با اسکن روی اینترنت خانگی |

عددی که برنامه نشان می‌دهد **«تأخیر کانفیگ»** است: همان «real delay» کلاینت‌ها. برنامه با لینک
`vless://` هر سرور، از داخل تونل یک درخواست واقعی می‌فرستد. این عدد برای **هر سرور جدا**
اندازه گرفته می‌شود، چون مسیر کلادفلر تا آلمان با مسیر تا ترکیه فرق دارد.

---

## ۱. کلادفلر (یک بار برای هر سرور)

| رکورد | ابر | مثال |
|---|---|---|
| دامنهٔ CDN (SNI) | نارنجی | `germany.example.com` |
| رکورد موبایل | خاکستری (DNS only) | `cdn1.germany.example.com` |
| رکورد خانگی (اختیاری) | خاکستری | `cdn2.germany.example.com` |

- **دامنهٔ CDN یک سطح زیر دامنهٔ اصلی باشد**؛ گواهی رایگان کلادفلر فقط `*.example.com` را پوشش
  می‌دهد.
- **رکوردهای خاکستری را برنامه خودش پر می‌کند.** اگر هنوز وجود نداشته باشند، می‌سازدشان.
- **توکن API:** `My Profile → API Tokens → Create Token → Edit zone DNS`
  - فقط دامنهٔ خودتان را انتخاب کنید.
  - دسترسی `Zone → Zone → Read` را هم اضافه کنید، یا Zone ID را در برنامه وارد کنید.

## ۲. پنل PasarGuard

برای هر سرور اصلی یک هاست CDN (و اگر رکورد خانگی دارید، یک هاست دوم):

| فیلد | 🛡 (موبایل) | 🛡 خانگی (اختیاری) |
|---|---|---|
| address | `cdn1.germany.example.com` | `cdn2.germany.example.com` |
| sni و host | `germany.example.com` | `germany.example.com` |
| ALPN / fingerprint | `http/1.1` / `chrome` | همان |

## ۳. نصب و راه‌اندازی

1. فایل `cfscan_ios.py` را در Pythonista وارد کنید: `+` و بعد `Import…`. اجرا کنید (▶).
2. **سرور:** لینک `vless://` کانفیگ CDN آن سرور را از پنل کپی کنید و «افزودن سرور» را بزنید.
   - لینک خودکار از کلیپ‌بورد برداشته می‌شود.
   - دامنه، path و پورت از لینک پر می‌شوند.
   - رکورد موبایل `cdn1.<دامنه>` پیشنهاد می‌شود.
   - رکورد خانگی را فقط اگر هاست خانگی جدا دارید وارد کنید.
   - UUID فقط در Keychain آیفون ذخیره می‌شود.
3. **توکن کلادفلر.**
4. برای سرور دوم: «تنظیمات ← سرورها ← + سرور جدید».

## ۴. استفاده

1. **VPN را خاموش کنید.**
2. **سرور را از بالای صفحه انتخاب کنید** (آلمان / ترکیه).
3. **«اسکن «آلمان» روی «ایرانسل»»** را بزنید.
   - **اینترنت خودکار تشخیص داده می‌شود** (از روی ASN، مثلاً AS44244 = ایرانسل).
   - **اینترنت ناشناخته:** یک بار می‌پرسد کدام است و موبایل است یا خانگی؛ مثلاً مخابرات یا شاتل
     برای اینترنت خانگی. دفعهٔ بعد خودش می‌شناسد.
   - **VPN روشن:** اگر کلادفلر گوشی را بیرون از ایران ببیند، اسکن انجام نمی‌شود.
   - **تشخیص اشتباه یا انجام‌نشده:** روی نوار اینترنت بزنید و «الان روی … هستم» را انتخاب کنید.
     اگر شمارهٔ شبکه (ASN) به اینترنت اشتباهی وصل شده بود، به اینترنت درست منتقل می‌شود و
     دفعه‌های بعد درست تشخیص داده می‌شود. اگر کلادفلر ASN را نگوید، برنامه می‌پرسد و حدس نمی‌زند.

### هر اسکن چه می‌کند

1. **بررسی رکورد:** IPهای فعلی رکورد (موبایل یا خانگی، بسته به اینترنت) روی همین اینترنت با
   تأخیر کانفیگ اندازه گرفته می‌شوند.
   - **همه سالم و سریع:** هیچ چیزی عوض نمی‌شود.
   - **سالم ولی کُند** (بیشتر از «تأخیر دلخواه»، پیش‌فرض ۷۰۰ms): اسکن خودش ادامه پیدا می‌کند
     و فقط اگر IPی حداقل ۲۰٪ سریع‌تر پیدا شود، عوضش می‌کند. وگرنه می‌گوید «IP سریع‌تری پیدا
     نشد» و همان می‌ماند.
   - **تأخیر دلخواه** در «تنظیمات ← پیشرفته» است. عدد ۰ این بررسی را خاموش می‌کند.
   - **دکمهٔ «دنبال IP سریع‌تر»:** وقتی نتیجه «سالم است» شد ولی از تأخیرش راضی نیستید، همین
     دکمه را در صفحهٔ اسکن بزنید. همان اسکن کامل دوباره روی همین اینترنت انجام می‌شود. لینک
     «دنبال IP سریع‌تر (حتی اگر سالم است)» در صفحهٔ اصلی هم همین کار را می‌کند.
2. **اسکن با اولویت:**
   1. IPهایی که برای همین سرور روی اپراتور دیگر همان گروه کار کرده‌اند (مثلاً وقتی روی ایرانسل
      هستید، IPهای خوب همراه اول)
   2. IPهایی که سرورهای دیگر روی همین اینترنت پیدا کرده‌اند
   3. IPهای خوب قبلی و همسایه‌های `/24` آن‌ها
   4. IPهای تصادفی
3. **اندازه‌گیری دقیق:** حداکثر ۳ IP همزمان، اولین تلاش کنار گذاشته می‌شود، میانه گزارش می‌شود.
4. **قانون‌های انتخاب:**
   - **سالم در همین لحظه:** IP باید روی همین اینترنت و در همین اسکن سالم باشد.
   - **اولویت با IP مشترک:** IPی که روی اپراتور دیگر گروه هم سالم بوده بر بقیه مقدم است.
   - **IPی که روی اپراتور دیگر خراب است هیچ‌وقت خودکار انتخاب نمی‌شود.** اگر فقط چنین IPی
     باشد، برنامه می‌گوید «IP سالم این اینترنت روی اینترنت دیگر خراب است» و انتخاب با شماست:
     «اعمال با این وجود» یا صبر کنید.
   - **پایداری:** IPهای فعلی که هنوز سالم‌اند نگه داشته می‌شوند (تغییر کمتر DNS)، مگر IP جدیدی
     پیدا شود که حداقل ۲۰٪ سریع‌تر باشد و به همان اندازه تأیید شده باشد. پس اسکنی که به‌خاطر خراب
     شدن یک IP انجام شده، IP کُند قبلی را هم کنار رکورد جدید نگه نمی‌دارد.
5. **به‌روزرسانی DNS.** اسکن موبایل **هیچ‌وقت** به رکورد خانگی دست نمی‌زند، و برعکس.


- **ساعت بالا** مدت اسکن را نشان می‌دهد. **آیکون چرخان** یعنی آن مرحله در حال اجراست.
- **نوار پیشرفت:** هر مرحلهٔ طولانی نوار و شمارندهٔ خودش را دارد.
- **جدول پایین** همیشه مال همان مرحله است:
  - اسکن سریع: فقط اینکه IP جواب می‌دهد
  - اندازه‌گیری دقیق: تأخیر کانفیگ که با هر IP تمام‌شده به‌روز می‌شود
- **آیکون‌ها:**
  - `✓` انجام شد
  - `✕` مشکل داشت
  - `–` لازم نشد یا متوقف شد
  - `❚❚` منتظر تأیید شما («اعمال روی DNS»)

### صفحهٔ اصلی

زیر انتخاب سرور یک خط کوچک هست: دامنهٔ CDN و نوع تست. «تأخیر کانفیگ ✓» یعنی لینک vless
تنظیم شده و عددها همان real delay کلاینت‌اند. اگر زرد نوشته «لینک کانفیگ را اضافه کنید»، عددها
فقط تا خود سرور است.

هر کارت یک برچسب وضعیت در گوشه دارد:

| برچسب | معنی |
|---|---|
| 🟢 سالم | IPهای رکورد روی همهٔ اپراتورهای گروه اخیراً سالم بوده‌اند |
| 🟡 کُند | سالم است ولی روی یک اپراتور از «تأخیر دلخواه» کُندتر است (عدد آن اپراتور زرد می‌شود) |
| 🟡 تأیید نشده | روی یک اپراتور هنوز (یا اخیراً) تست نشده؛ با همان اپراتور اسکن کنید |
| 🔴 خراب | یکی از IPها روی یک اپراتور جواب نداده؛ اسکن کنید |
| 🟡 بدون IP / تنظیم نشده | رکورد هنوز IP ندارد، یا نام رکورد وارد نشده |

```
موبایل                         [تأیید نشده]
cdn1.germany.example.com
104.19.201.44
[همراه اول 420] [ایرانسل ؟]
همراه اول ✓ · ایرانسل ⚠ تأیید نشده
آخرین تغییر: ۲ ساعت پیش
```

«⚠ تأیید نشده» یعنی: سیم را عوض کنید و روی همان اپراتور اسکن کنید. برنامه اول IPهای فعلی را
تست می‌کند و اگر سالم باشند، فقط تأییدشان می‌کند.

**حالت تاریک:** اگر آیفون روی Dark Mode باشد، برنامه با رنگ‌های تیره باز می‌شود (Pythonista
نسخهٔ ۳.۳ به بعد). همهٔ رنگ‌ها در هر دو حالت برای خوانایی تست شده‌اند.

### همهٔ سرورها

«همهٔ سرورها روی این اینترنت» هر سرور را پشت سر هم اسکن می‌کند. سرورهای بعدی از IPهایی که
سرور قبلی پیدا کرد شروع می‌کنند. آخر کار نتیجهٔ هر سرور نمایش داده می‌شود.

## ۵. منوها

**تنظیمات:**
- ویرایش سرور انتخاب‌شده
- سرورها
- کلادفلر (توکن، Zone ID، تعداد IP در رکورد، اعمال خودکار)
- اینترنت‌ها (نام، موبایل/خانگی، ASNها)
- پیشرفته (تأخیر دلخواه، حد تأخیر سالم، حداقل بهبود، مهلت‌ها و …)

**ابزارها:**
- جدول IPهای سرور (هر IP روی هر اینترنت)
- تاریخچه
- تست یک IP
- تنظیم دستی و برگرداندن رکورد
- تست کلادفلر
- تشخیص دوبارهٔ اینترنت
- رنج‌های کلادفلر
- پاک کردن حافظه
- کپی و وارد کردن تنظیمات (بدون توکن و UUID)
- کپی لاگ

## به‌روزرسانی از نسخه‌های قبلی

- **رکوردها:** «رکورد آدرس» هر سرور به رکورد موبایل و «رکورد دوم» به رکورد خانگی تبدیل می‌شود.
- **جدول قبلی:** برای هر سرور کپی می‌شود. اینکه هر IP روی هر اینترنت کار می‌کرد نگه داشته
  می‌شود، ولی عدد تأخیرش نه (با آن سرور گرفته نشده بود).
- **اینترنت‌ها:** همراه اول و ایرانسل ASN خودشان را می‌گیرند. «خانگی» اولین بار که از خانه اسکن
  کنید ASN را یاد می‌گیرد.

## رفع اشکال

| پیام | معنی |
|---|---|
| «VPN روشن است» | کلادفلر گوشی را بیرون از ایران می‌بیند؛ اسکن انجام نمی‌شود. |
| «این اینترنت کدام است؟» | ASN جدید است؛ یک بار انتخاب کنید. |
| «IP سالم این اینترنت روی اینترنت دیگر خراب است» | فقط IPهایی پیدا شد که روی اپراتور دیگر گروه بسته‌اند. |
| «⚠ روی ایرانسل تأیید نشده» | روی ایرانسل هم اسکن کنید. |
| «همه timeout شدند» | اینترنت قطع است یا همهٔ کاندیدها بسته‌اند. |
| «اتصال TLS قطع می‌شود» | احتمالاً SNI دامنهٔ CDN روی این اینترنت فیلتر است؛ دامنهٔ ذخیره را جایگزین کنید. |
| «تونل باز شد ولی…» / «tunnel …» | UUID لینک، فعال بودن کاربر، یا فیلتر ترافیک بعد از اتصال. |
| «پاسخ 404» / «خطای 5xx» | path اشتباه / کلادفلر به سرور نمی‌رسد. |
| «zone not found» | دسترسی `Zone:Read` به توکن بدهید یا Zone ID را وارد کنید. |

اگر برنامه بسته شد: «ابزارها ← کپی لاگ برای گزارش خطا».

**فایل اطلاعات خراب شد؟** برنامه باز می‌شود و از اول شروع می‌کند. فایل خراب با نام
`cfscan_ios_data.json.broken-…` کنار برنامه نگه داشته می‌شود و پاک نمی‌شود. مقدارهای عجیب داخل
فایل (مثلاً بعد از ویرایش دستی) نادیده گرفته می‌شوند و بقیهٔ تنظیمات می‌ماند.

## تست‌ها (برای توسعه)

```
python3 -m unittest tests.test_ios_app tests.test_ios_ui
```

- **`test_ios_app`:**
  - موتور: قانون‌های انتخاب، اسکن، مهاجرت داده‌ها
  - پروتکل: VLESS روی یک سرور TLS محلی
  - مقاومت: فایل‌های خراب و تصادفی، نوشتن همزمان
- **`test_ios_ui`:** همهٔ صفحه‌ها و منوها با Pythonista شبیه‌سازی‌شده (`tests/fake_pythonista`):
  - سناریوها: همراه اول ← ایرانسل، VPN روشن، اینترنت ناشناخته، ASN اشتباه، تعارض، همهٔ سرورها،
    توقف وسط اسکن
  - چیدمان در عرض همهٔ آیفون‌ها
  - حالت تاریک و کنتراست رنگ‌ها
