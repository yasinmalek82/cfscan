# CF Scanner برای آیفون (Pythonista)

با این برنامه روی خود آیفون، با عوض کردن اینترنت گوشی، برای هر اپراتور یک IP تمیز
کلادفلر پیدا می‌کنید. بعد از تست، برنامه خودش رکورد DNS همان اپراتور را در کلادفلر
به IP جدید تغییر می‌دهد. پنل PasarGuard دست نمی‌خورد.

| فایل | کاربرد |
|---|---|
| `cfscan_ios.py` | برنامهٔ اصلی |
| `pythonista_smoke_test.py` | تست اولیهٔ یک‌صفحه‌ای (اختیاری) |

---

## ۱. آماده‌سازی کلادفلر (یک بار)

1. **دامنهٔ CDN:** مثلاً `cdn.example.com` با **ابر نارنجی**. همین دامنه SNI و Host کانفیگ‌هاست.
2. **برای هر اپراتور یک زیردامنه با ابر خاکستری (DNS only)** و TTL برابر `1 min`:
   `mci.example.com`، `mtn.example.com`، `home.example.com`.
   اول هر کدام را به یک IP کلادفلر که الان کار می‌کند اشاره بدهید.
3. **توکن API:**
   `My Profile → API Tokens → Create Token → Edit zone DNS`
   - در Zone Resources فقط دامنهٔ خودتان را انتخاب کنید.
   - یک دسترسی دیگر هم اضافه کنید: `Zone → Zone → Read`.
     اگر نمی‌خواهید، **Zone ID** را از صفحهٔ Overview دامنه کپی کنید و در تنظیمات برنامه وارد کنید.

   این توکن فقط DNS همان دامنه را تغییر می‌دهد. اگر گوشی گم شد، از همان صفحه باطلش کنید.

## ۲. آماده‌سازی پنل PasarGuard (یک بار)

برای هر اپراتور یک هاست جدا بسازید:

| فیلد | مقدار |
|---|---|
| address | زیردامنهٔ همان اپراتور، مثلاً `mci.example.com` |
| sni و host | `cdn.example.com` |
| path | خالی (از inbound خوانده می‌شود) |
| ALPN | `http/1.1` |
| fingerprint | `chrome` |

## ۳. نصب روی آیفون

1. فایل `cfscan_ios.py` را در Files ذخیره کنید.
2. در Pythonista، در فهرست فایل‌ها دکمهٔ `+` را بزنید، `Import…` را انتخاب کنید و فایل را وارد کنید.
   (راه دیگر: یک فایل خالی بسازید و متن کامل فایل را داخلش بچسبانید.)
3. اجرا کنید (▶). بار اول صفحهٔ تنظیمات باز می‌شود.
4. **آیکون روی صفحهٔ اصلی:** در تنظیمات Pythonista، بخش Shortcuts / Home Screen، همین
   اسکریپت را انتخاب کنید تا آیکونش روی صفحهٔ اصلی بیاید.

برنامه دو فایل کنار خودش می‌سازد:
- `cfscan_ios_data.json`: تنظیمات، وضعیت اپراتورها و تاریخچه، **بدون توکن**. توکن در Keychain آیفون است.
- `cfscan_ios_log.txt`: لاگ مراحل، برای گزارش خطا.

## ۴. تنظیمات برنامه

- **کانفیگ**
  - دامنهٔ CDN
  - WebSocket path: همان path inbound. اگر خالی باشد فقط `/cdn-cgi/trace` تست می‌شود.
  - پورت و TLS
- **کلادفلر**
  - توکن
  - Zone ID (اختیاری)
  - TTL
  - تعداد IP در هر رکورد (۱ تا ۳)
  - اعمال خودکار یا با تأیید شما
- **اسکن**
  - تعداد کاندید (پیش‌فرض ۵۰۰) و تست همزمان (۳۲)
  - مهلت هر اتصال
  - توقف بعد از N پاسخ
  - تعداد IP و تعداد تلاش برای تأیید دقیق
  - حداکثر افت و پینگ «سالم»
  - فیلتر دیتاسنتر (مثلاً `FRA,AMS`)
  - IPv6
  - مدت نادیده گرفتن IPهای بد

زیردامنهٔ هر اپراتور را از «ابزارها ← اپراتورها و زیردامنه‌ها» تنظیم کنید. اپراتور جدید هم از
همان‌جا اضافه می‌شود، مثلاً رایتل یا یک وای‌فای دیگر.

## ۵. استفاده

1. **VPN را خاموش کنید** و اینترنت گوشی را روی سیم همان اپراتور بگذارید.
2. در کارت همان اپراتور «تست و اصلاح» را بزنید:
   1. **بررسی IP فعلی:** اگر سالم باشد، کاری انجام نمی‌شود.
   2. **اسکن:** اول IPهایی که قبلاً روی همین اپراتور جواب داده‌اند و همسایه‌های `/24` آن‌ها،
      بعد IPهای تصادفی از رنج کلادفلر.
   3. **تأیید دقیق** سریع‌ترین‌ها با چند تلاش. اگر path تنظیم شده باشد، با درخواست واقعی WebSocket.
   4. **تغییر رکورد DNS.** اگر API کلادفلر بدون VPN در دسترس نباشد، درخواست از طریق همان IP تمیز
      فرستاده می‌شود.
3. روی هر ردیف نتیجه بزنید تا همان IP اعمال، کپی یا دوباره تست شود.

دکمهٔ **«بیشتر»** در هر کارت:
- فقط بررسی
- اسکن کامل حتی اگر IP فعلی سالم است
- تنظیم IP دستی
- برگرداندن IP قبلی
- IPهای خوب ذخیره‌شده
- تاریخچه
- ویرایش

**ابزارها:**
- تاریخچهٔ همهٔ تغییرات
- تست یک IP دلخواه
- تست اتصال به کلادفلر (توکن و رکوردها)
- به‌روزرسانی رنج IP کلادفلر
- پاک کردن حافظهٔ IPهای بد
- کپی و وارد کردن تنظیمات، برای گوشی دیگر و بدون توکن
- کپی لاگ

## رفع اشکال

| پیام | معنی |
|---|---|
| «به نظر VPN روشن است» | کلادفلر شما را خارج از ایران دیده؛ VPN را خاموش کنید. |
| «همه timeout شدند» | اینترنت قطع است، یا روی این اپراتور همهٔ کاندیدها بسته‌اند؛ دوباره اسکن کنید. |
| «اتصال TLS قطع می‌شود» | احتمالاً SNI دامنهٔ CDN شما روی این اپراتور فیلتر است. |
| «پاسخ 404» | path تنظیمات با path inbound سرور یکی نیست. |
| «خطای 5xx» | کلادفلر به سرور شما وصل نشد؛ سرور، پورت یا حالت SSL را بررسی کنید. |
| «zone not found» | توکن دسترسی `Zone:Read` ندارد؛ یا اضافه‌اش کنید یا Zone ID را وارد کنید. |

اگر برنامه بسته شد: «ابزارها ← کپی لاگ برای گزارش خطا» را بزنید و متن را بفرستید.
