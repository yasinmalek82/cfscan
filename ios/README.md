# CF Scanner برای آیفون (Pythonista)

**هر سرور CDN یک رکورد آدرس خودش را دارد**، مثلاً `cdn1.germany.example.com` برای آلمان و
`cdn1.turkey.example.com` برای ترکیه. این همان `address` هاست CDN آن سرور در پنل است.

تمیز بودن یک IP کلادفلر به **اینترنت مشتری** بستگی دارد. برای همین اندازه‌گیری‌ها مشترک‌اند:
روی هر اینترنت یک بار «اسکن این اینترنت» می‌زنید، نتیجه در یک **جدول پوشش** ذخیره می‌شود
(هر IP روی هر اینترنت)، و **رکورد همهٔ سرورها با هم** از روی همین جدول به‌روز می‌شود. هر IP روی
خود همان سرور با درخواست WebSocket تأیید می‌شود.

| فایل | کاربرد |
|---|---|
| `cfscan_ios.py` | برنامه |
| `pythonista_smoke_test.py` | تست اولیهٔ یک‌صفحه‌ای (اختیاری) |

---

## ۱. کلادفلر (یک بار)

برای هر سرور دو رکورد لازم است:

| رکورد | ابر | مثال | کاربرد |
|---|---|---|---|
| دامنهٔ CDN | نارنجی | `germany.example.com` | SNI و Host کانفیگ |
| رکورد آدرس | خاکستری (DNS only) | `cdn1.germany.example.com` | address کانفیگ؛ برنامه پرش می‌کند |

- **دامنهٔ CDN یک سطح زیر دامنهٔ اصلی باشد.** گواهی رایگان کلادفلر فقط `*.example.com` را
  پوشش می‌دهد. رکورد آدرس خاکستری این محدودیت را ندارد و می‌تواند دوسطحی باشد.
- **رکورد دوم (اختیاری):** مثلاً `cdn2.germany.example.com`. فقط وقتی لازم است که برای یک
  اینترنت (مثلاً خانگی) IP مشترکی با بقیه پیدا نشود.
- **توکن API:** `My Profile → API Tokens → Create Token → Edit zone DNS`
  - فقط دامنهٔ خودتان را انتخاب کنید.
  - دسترسی `Zone → Zone → Read` را هم اضافه کنید، یا Zone ID را در برنامه وارد کنید.
- **پیشنهاد:** یک دامنهٔ ارزان دوم هم در کلادفلر نگه دارید. اگر SNI دامنهٔ اصلی روی یک
  اپراتور فیلتر شد، فقط SNI هاست‌ها را در پنل عوض می‌کنید.

## ۲. پنل PasarGuard

هاست CDN فقط برای **۱ یا ۲ سرور اصلی** لازم است:

| فیلد | آلمان | ترکیه |
|---|---|---|
| address | `cdn1.germany.example.com` | `cdn1.turkey.example.com` |
| sni و host | `germany.example.com` | `turkey.example.com` |
| ALPN | `http/1.1` | `http/1.1` |
| fingerprint | `chrome` | `chrome` |

لیست پیشنهادی برای مشتری، به ترتیب (فیلد priority):

```
📊 {DATA_LEFT} مانده · ⏳ {DAYS_LEFT} روز
DE ⚡              Reality
DE 🛡              CDN (address: cdn1.germany…)
SWE ⚡
TR ⚡ 🎮 گیم
TR 🛡              CDN (address: cdn1.turkey…)
UK ⚡ 📈 ترید
⛔ اشتراک تمام شده — تمدید: @…     (status: expired, limited)
```

متن راهنما (announce): «اول ⚡، اگر وصل نشد 🛡 · برای انتخاب، پینگ همه را بگیرید.»

## ۳. نصب روی آیفون

1. فایل `cfscan_ios.py` را در Files ذخیره کنید.
2. در Pythonista، در فهرست فایل‌ها دکمهٔ `+` را بزنید، `Import…` را انتخاب کنید و فایل را وارد کنید.
3. اجرا کنید (▶). بار اول می‌پرسد:
   - **سرور CDN:** دامنه، path و رکورد آدرس. اگر رکورد را خالی بگذارید، `cdn1.<دامنه>`
     پیشنهاد می‌شود.
   - **توکن کلادفلر.**
4. **سرور دوم:** از «تنظیمات ← سرورهای CDN و رکوردها ← + سرور جدید».
5. **آیکون روی صفحهٔ اصلی:** در تنظیمات Pythonista، بخش Shortcuts / Home Screen.

## ۴. استفاده: فقط یک دکمه

1. **VPN را خاموش کنید.** نوار وضعیت باید سبز باشد: «اینترنت ایران».
2. **بالای صفحه انتخاب کنید الان روی کدام اینترنت هستید:** همراه اول، ایرانسل، خانگی یا …
3. **«اسکن این اینترنت»** را بزنید. برنامه:
   1. IPهای فعلی رکورد همهٔ سرورها را روی همین اینترنت تست می‌کند. اگر همه سالم باشند،
      کار تمام است.
   2. اگر نه، اسکن می‌کند. اول IPهایی که روی اینترنت‌های دیگر کار کرده‌اند تست می‌شوند.
   3. برای **هر سرور** IPهایی را انتخاب می‌کند که روی بیشترین اینترنت‌ها کار می‌کنند، با کمترین
      «بدترین پینگ»، و هر کدام را روی **خود همان سرور** با WebSocket تأیید می‌کند.
   4. رکورد هر سرور را در کلادفلر به‌روز می‌کند. معمولاً همهٔ سرورها IPهای یکسان می‌گیرند، مگر
      اینکه یک سرور IPی را رد کند.
4. **سیم را عوض کنید و دوباره بزنید.** برای هر سرور یک کارت در صفحهٔ اصلی هست که نشان می‌دهد
   هر IP روی کدام اینترنت کار می‌کند:

```
آلمان
cdn1.germany.example.com
104.19.201.44
[همراه اول 52] [ایرانسل 80] [خانگی ✕]
پوشش: همراه اول ✓ · ایرانسل ✓ · خانگی ✓
```

**اگر هیچ IP مشترکی با یک اینترنت (مثلاً خانگی) نباشد:**
- **بدون رکورد دوم:** رکورد آن سرور برای آن اینترنت یک IP جدا هم می‌گیرد، تا هیچ اینترنتی
  بی‌IP نماند.
- **با رکورد دوم:** اگر این وضعیت ادامه داشت، «رکورد دوم» را برای آن سرور تنظیم کنید و در پنل
  یک هاست CDN دوم با همان address بسازید. از آن به بعد IP جدای آن اینترنت روی رکورد دوم می‌رود.

نتیجهٔ هر اینترنت ۴۸ ساعت معتبر است. قابل تغییر در «تنظیمات ← پیشرفته».

## ۵. منوها

**تنظیمات:**
- سرورهای CDN و رکوردها
- کلادفلر (توکن)
- اینترنت‌ها: مثلاً رایتل یا شاتل اضافه کنید
- پیشرفته

**ابزارها:**
- جدول همهٔ IPها (★ = در یک رکورد)
- تاریخچه
- تست یک IP روی این اینترنت
- تنظیم دستی یک رکورد
- برگرداندن رکورد به IP قبلی
- تست کلادفلر
- بررسی اتصال
- رنج‌های کلادفلر
- پاک کردن حافظه
- کپی و وارد کردن تنظیمات
- کپی لاگ

**روی ردیف‌های صفحهٔ اسکن** بزنید: کپی، تست دوباره، یا گذاشتن روی رکورد یک سرور.

**به‌روزرسانی از نسخه‌های قبلی:**
- سرورها و اینترنت‌ها منتقل می‌شوند و IPهای خوب قبلی وارد جدول پوشش می‌شوند.
- در نسخهٔ ۳، نام رکورد `ip1` به سرور اول داده می‌شود. برای سرور دوم، رکورد را در
  «سرورهای CDN و رکوردها» وارد کنید.
- زیردامنه‌های قدیمی (`mci.cdn…` و غیره) در کلادفلر دست نمی‌خورند؛ بعد از یکی دو هفته پاکشان کنید.

## رفع اشکال

| پیام | معنی |
|---|---|
| «VPN روشن است» | کلادفلر شما را خارج از ایران دیده است. |
| «همه timeout شدند» | اینترنت قطع است یا همهٔ کاندیدها بسته‌اند؛ دوباره اسکن کنید. |
| «اتصال TLS قطع می‌شود» | احتمالاً SNI دامنهٔ CDN روی این اینترنت فیلتر است؛ دامنهٔ ذخیره را جایگزین کنید. |
| «پاسخ 404» | path سرور با inbound یکی نیست. |
| «خطای 5xx» | کلادفلر به سرور وصل نشد؛ سرور، پورت یا حالت SSL را بررسی کنید. |
| «zone not found» / «اجازهٔ دیدن دامنه‌ها» | دسترسی `Zone:Read` را به توکن بدهید یا Zone ID را وارد کنید. |
| «رد شد روی ترکیه: …» | آن IP روی سرور ترکیه با WebSocket جواب نداد؛ ترکیه IP دیگری گرفت. |

اگر برنامه بسته شد: «ابزارها ← کپی لاگ برای گزارش خطا» را بزنید و متن را بفرستید.
